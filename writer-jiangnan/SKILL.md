# 江南体写作引擎（writer-jiangnan）

> **一句话内核**：江南的本事，是让**一个不勇敢的人**，用**他仅有的那点词**，讲**一件大到装不下的事**。

这个 skill 不是"模仿江南的文风"，而是把他推进叙事、塑造人物、控制节奏的**可复用动作**拆开，让你能在自己的故事里调用。

## 1. 江南的四张脸：先选模式

他不是一种风格，是**四种**。选错模式，写出来就不像。

| 模式 | 代表 | 人称 | 语体 | 情感引擎 | 结局形状 | 主要风险 |
| --- | --- | --- | --- | --- | --- | --- |
| **A 校园回忆体** | 《此间的少年》 | 全知说书人 | 口语 + 伪史料腔 + 时间错置 | 散场（没人死，但都走了） | 校门口：新人从远处走来 | 主线散、标签化 |
| **B 末日第一人称** | 《上海堡垒》 | 第一人称限知 | 技术语言 × 自嘲 | 迟到的真相（说不出口） | 错位重逢：抱住你的不是她 | 自怜、设定倾泻 |
| **C 都市奇幻成长** | 《龙族》 | 第三人称限知滑入自由间接引语 | 神话日常化混语体 | 糖刀（先给糖再夺走） | 安静尾声 + 新钩子 | 比喻依赖、谜团通胀 |
| **D 东方史诗** | 《九州·缥缈录》 | 第三人称限知 + 史书全知 | 半文半白、四字句、大词 | 预叙宿命（先写他的死） | 名单式的散场 | 体积失控、女性缺席 |

**杂交规则**（江南自己就在杂交）：

```
A 的亲切 × C 的神话 = 都市校园奇幻
B 的自嘲 × D 的史书 = 战争回忆录
A 的散场 × B 的装置 = 青春告别小说（最容易写好的一种）
```

**不许三种以上杂交。** 每多一层语体，读者的进入成本翻倍。

## 2. 从零开写：七步流程

### Step 1 · 定模式与体量

先回答三件事，写下来，不要跳过：

1. 这是四种模式里的哪一种？（可以杂交两种）
2. 多长？（3000 字短篇／8000 字短篇／5 万中篇／20 万以上长篇）
3. 读者读完应该**难受还是暖**？（江南 90% 是"难受但暖"）

### Step 2 · 造叙述者的"声音卡"（**这一步决定成败**）

江南的每一本书，叙述者都只有**一套词汇、一种句长、一个自我评价**。

写一张卡，五行，贴在文档开头：

```
自称：      算泡泡的 / 死小孩 / 我这号人 / 我这种人
自我评价：  怂、没本事、不配、运气好
三个口头禅：我靠 / 其实 / 谁知道呢
句子长度：  短（12-20 字为主），情绪高时更短
他绝不说的词：励志、梦想、奋斗、逆袭、正能量
```

> 四本书的现成声音卡见 `references/voice-bank.md`。

### Step 3 · 选一个"装置"

书目里的每一本都有一个**反复出现的物理装置**：

| 书 | 装置 | 功能 |
| --- | --- | --- |
| 上海堡垒 | 手机与短信 | 想说而说不出 |
| 此间的少年 | 莫大的二胡 | 时间刻度 |
| 龙族 | 明信片 / 钥匙 / 玩具 | 迟到的真相 |
| 缥缈录 | 豹尾 / 指套 / 誓言 | 传承与身份 |

**规则：一部作品只用一件装置，出现三次。**

第一次：日常（不显眼）；第二次：转折（有了意义）；第三次：收束（全部意义压上来）。
第三次出现时**不要解释**，加一句日常台词把镜头移开。

### Step 4 · 定糖与刀

江南的情感工程说明书是他自己写的：

> "喜剧中欢乐是为了让人笑，而悲剧中的欢乐是为了让人在结尾时的悲伤加倍，你曾有多快乐，就得用双倍的悲伤来买单。"

操作顺序：

1. **糖**：给角色一个**可爱的怪癖 + 一件便宜的东西 + 一段无用的日常**（吃饭、打游戏、挑衣服、走夜路）。
2. **读者自满**：让这段日常持续到读者觉得"这书其实挺轻松"。
3. **刀**：夺走它——但**必须由人物自己的选择造成**，不能靠车祸、天灾、作者安排。
4. **补刀**：用一个物件或一句迟到的话，把真相补上。

**糖刀最短可用配比**：3000 字短篇 → 糖 1800 字，刀 800 字，补刀 400 字。

### Step 5 · 先写结局的形状

三种结尾，选一种，**先把它写出来**（哪怕只有 50 字），再回头写开头：

| 结尾 | 用法 | 例 |
| --- | --- | --- |
| **错位重逢** | 主角没得到他想要的，但撞上一个必须继续活下去的日常瞬间 | "要我去弄点爆米花么？""嗯，如果他们有的话。" |
| **迟到的真相** | 一件旧物揭示他当时不知道的事 | 储物柜里那张早已失效的登机牌 |
| **散场** | 没有人死，人都走了；新人从远处走来 | "很快就有新的郭靖杨康们会从远处走来。" |

**三条禁忌**：不许痛哭独白；不许"我终于明白了"；不许用死亡收束最后一段。

### Step 6 · 写第一段

**① 冷开场 + 对话**（B、D 用）

```
"上海也会下沉么？"
"难说，自己做好准备。"
"准备？"
"囤积点瓶装水和面包。"
```

> 三句对话 + 一个时代。**不解释、不铺垫、不加"他心想"。**

**② 先声后形**（D 用）

```
阿苏勒醒来听见的第一个声音是水声，满耳的水声，像是整个世界都在下雨。
```

> 先给感官碎片，再让人物对上号。

**③ 旁观者定时**（A 用）

```
又是汴梁的秋天，积累了整整一个春夏的枝叶悄然凋零，几片落叶的背后，是二胡嘶哑的弦歌。
```

> 先用一个不属于主线的人和环境给全书定调，再接"而我们的故事，也是从那个时间和空间点上开始的"。

### Step 7 · 写完必须自查

跑 §6 的清单 + `scripts/style_check.py`。

## 3. 句子层引擎（最核心，也最容易学）

### 3.1 三种"江南句"

**句一 · 认知翻转句**

```
其实 X。原来 X。所谓 X，就是 Y。
```

> "所谓伟大的忍术传统，本来就是一场骗局。"
> "其实生日什么的对路明非无所谓。谁会记得？"

用法：一段建立预期，下一段用一个词翻过来。**每千字最多 1.5 次**（四本书实测 3.2–7.7 次/万字）。

**句二 · 预叙句**

```
很多年以后，X。／许多年之后，X 死在 Y。
```

> "他们握了手，于是第一个人和第二个人就此相逢。霸业或者宿命，都由此开始。"
> "许多年之后，青阳昭武公吕归尘阿苏勒死在他金色的帐篷中。"

用法：**一部作品用两次**——一次给主角的结局，一次给一段关系的结局。**用第三次就变套路。**

**句三 · 假设排比句**

```
如果 X，你会不会 Y？你要去 Z 么？也去 A 么？
```

> "说了那个后果你怕不怕？你要去抓她的手么？也去抓她的任性她的眼泪她的理想……"

用法：只在情绪最高点用**一次**，四到六问，然后立刻收住。超过六问就是抒情失控。

### 3.2 段落呼吸：短—长—短，且大量单句成段

实测数据（必记）：

| 作品 | 单句成段占比 | 段落中位字数 | 句长中位数 |
| --- | --- | --- | --- |
| 上海堡垒 | **47.2%** | 30.5 | 20 |
| 此间的少年 | 40.8% | 35 | 24 |
| 九州·缥缈录 | 35.7% | 36 | 22 |
| 龙族 I | 32.2% | 32 | 15 |

**操作**：

- 情绪越高，段落越短。**高潮段的段落可以短到 6 个字。**
- 说明段可以长（60–120 字），但**一段只许有一个新信息**。
- 每三到五段之间，插一个**单句成段**。
- 对话之后**必须**跟一个动作、一个环境、或一个物件——不许连着两行裸对话超过四轮。

### 3.3 比喻配额

| 作品 | 比喻密度（每万字） |
| --- | --- |
| 上海堡垒 | 29.2（最抒情） |
| 九州 | 20.5 |
| 龙族 I | 21.3（实测） |
| 此间 | 8.4（几乎不用） |

**配比规则**：

- 抒情/奇幻：15–25 个/万字
- 校园/喜剧：5–10 个/万字（**喜剧靠错位，不靠比喻**）
- **同一段不许出现两个"像是"**
- 喻体必须来自**这个人物看得见的东西**（士兵用兵器、学生用课本、技术员用参数）。**不许用作者知道而人物不知道的喻体。**

### 3.4 对话的四条规矩

1. **每个人有一套词**：外号、句长、称呼、脏话程度。写之前列表。
2. **对话必须同时干两件事**：推进 + 暴露性格。只干一件的对话删掉。
3. **用答非所问写潜台词**：重要的情感永远不在台词里。
   > "'那双带白色毛边的靴子，其实我买了的。'／'早都不流行了啊。'／'不过我还是要！'"
4. **强者说话越短**：
   > "'报告给我，你可以滚蛋了。'将军冲我行了一个很不正规的军礼。"

### 3.5 用词纪律

**禁用**：励志、梦想（除反讽）、逆袭、正能量、成长、蜕变、治愈。

**慎用（有配额）**：

| 词 | 配额 |
| --- | --- |
| 忽然 | ≤10 次/万字（江南实测 5.5–10） |
| 突然 | 几乎不用，江南用"忽然"（实测 0–0.5/万字） |
| 仿佛 | ≤4 次/万字（史诗可到 4，校园 0–1） |
| 其实 / 原来 / 所谓 | 合计 ≤8 次/万字 |
| 感叹号 | 校园 10–18/万字；第一人称 0–3/万字；都市奇幻 15–70；史诗 30–55（**四者不可混用**） |
| 省略号 | 20–27 次/万字（第一人称犹疑的语气标记） |

## 4. 人物层

### 4.1 四件套速写（江南最稳定的人物技术）

```
外号 / 别人怎么叫他
身体 / 一个别人不会有的身体事实（一米九五、500 度近视、手比别人的脏）
癖好 / 一个无用的小动作（在课本上画乌龟、把诗写在厕所门板）
口头禅 / 一句话，重复到读者会背
```

### 4.2 江南的四种人物原型

| 原型 | 内核 | 台词特征 | 危险用法 |
| --- | --- | --- | --- |
| **衰小孩** | 我怕，但我不能不管 | 自嘲、吐槽、短句、结巴 | 写成纯搞笑工具 |
| **硬汉 / 长辈** | 我不解释，但我会做 | 极短、命令式、脏话 | 所有硬汉声音趋同 |
| **女神 / 大小姐** | 我看透你，但我不说 | 命令 + 玩笑 + 昵称 | **变成道具（最大风险）** |
| **谋士 / 反派** | 我越温和，你越该怕 | 反问、典故、微笑 | 魅力盖过主角 |

### 4.3 让强者平静（江南最狠的一手）

**规则**：越是残忍的决定，越要用温和的句法说出来；**让旁观者的感官和强者不一致**。

> 九王抽动鼻子，像是闻着馥郁的酒香："这风里的味道，让人想起铁沁王奔驰在这片草原上的年代。"
> 比莫gān 愣了一下，风里只有浓重的灼烧气息和血腥味。

**同一个风，一个人闻到酒香，一个人闻到血腥。** 不写一句评语，高下立见。

### 4.4 女性角色纠偏（**强制规则，江南自己的短板**）

江南四本书的通病：女性角色多为"被守护的对象"，少有**自己的欲望和选择**。

写之前，为每一个重要女性角色填这一行，填不出就删掉这个角色：

```
她想要的东西：________（不能是"男主角"）
她会为此做的、会伤害主角的事：________
她独处时做的一件事（与主角无关）：________
```

**并且：不许让她的死成为男主角的成长道具。** 如果要写她的死，必须是她自己选择的结果。

### 4.5 称呼与届别（**同人第一红线**）

写**同人**时，人物关系不是背景，是**读者的条件反射**。文笔再像，只要谁叫谁一声叫错，读者立刻判定「写的人不认识这些人」。

**硬性动作（写同人前必须做，不做不许动笔）：**

1. **抄录，不回忆。** 从原作资料里抄下五样：人物名单 / 届别与身份 / 专有名词写法 / 时间线 / 当前状态边界。
2. **画称呼矩阵。** 每一格（谁叫谁什么）都必须有原作依据，**不能推**。
3. **写完搜一遍**「师兄/师姐/师弟/师妹/学长/学姐」，逐条确认说话人。

```
          │ 楚子航        路明非        夏弥
──────────┼────────────────────────────────
楚子航 叫 │ —            明非          夏弥
路明非 叫 │ 师兄          —             师妹
夏弥   叫 │ 楚子航/师兄   师兄          —
```

**两条最容易犯的错：**

- **推出来的称呼。** 「A 是 B 的师兄」+「C 是 B 的师妹」，**推不出**「A 是 C 的师兄」——届别差不是传递关系，逐对核。
- **跟着气场走。** 谁说话像姐姐，谁就被叫成师姐。**气场不是届别**，届别由入学顺序定。

**称呼对完之后，让它去干活：** 称呼同时携带层级、亲疏、此刻的情绪。想写「她服软了」，别写心理，**让她改口叫一次**；想写「生分了」，**让对方换回敬称**。**改口一部短篇最多一次。**

> 完整检查表、雷区、改动边界、真实案例见 `references/canon-fidelity.md`。
> 一句话：**称呼错了，不是瑕疵，是你告诉读者「我不认识这些人」。**

## 5. 结构层

### 5.1 短篇（3000 字）——最稳的模板

```
1. 冷开场 / 一句对话（150 字）        定调，不解释
2. 日常的世界 + 两个人的关系（900 字）  糖：怪癖 + 便宜的东西 + 无用的日常
3. 装置第一次出现（不显眼）             埋
4. 一件小事打破了日常（600 字）         危机，但看起来很小
5. 选择（400 字）                    人物自己选错
6. 刀（600 字）                      失去
7. 装置第三次出现（150 字）            补刀，不解释
8. 日常台词收尾（80 字）               镜头移开
```

### 5.2 短篇（8000 字）

在上面基础上，把第 2 步拆成两场（一场给关系，一场给世界），第 6 步拆成两场（一场给事件，一场给余震）。

### 5.3 长篇（20 万以上）

**三级结构**：卷（6 卷左右）— 幕（每卷 5–10 章）— 节（每章 3–6 节，每节 2000–4000 字）。

**单卷模板**：

1. 冷开场 / 神话序章：一个宏大的谜团或一场战斗
2. 日常世界：主角的处境
3. 激励事件：一封信、一次任务、一个人
4. 组队与调查：新角色逐个登场
5. 中点反转：以为是 A，其实是 B
6. 高潮场面：**一个视觉上独一无二的大场面**
7. 代价：一个重要角色死亡或离开
8. 安静尾声 + 新钩子

**系列级的三条保险**（防止江南式的"收不回来"）：

1. **每卷回答一个局部问题，只开一个新问题**（不许开得比答得快）
2. **给主角一个倒计时的代价**（每次用力量都失去一点什么）
3. **列一张人物名单，标上"必须在第几卷退场"**——先定讣告，再写生平

### 5.4 糖刀曲线（一章之内）

```
日常／搞笑 → 亲密／暧昧 → 小危机 → 解决／发糖 → 更大的危机 → 失去 → 迟到的真相 → 余震
```

**每 10 章检查一次**：主线推进了吗？糖和刀的比例是多少？如果连续 3 章只有糖，删一章。

### 5.5 章末钩子只有三种，不许发明第四种

1. **一个未回答的问题**（人物说了半句话）
2. **一个突然出现的人 / 物**
3. **一句预叙**（"他没想到，这是他最后一次看见她。"）

**配额：一章最多一个。** 每章都断在刀口上 = 悬念通胀 = 读者疲劳。

## 6. 发稿前自查

### 6.1 十六条清单（逐条打勾，不勾就改）

**声音**
- [ ] 叙述者有一张声音卡，且全文没有偏离
- [ ] 主角的自我评价是"贬低"的，不是"昂扬"的
- [ ] 全书没有"励志/梦想/逆袭/成长"这类词（反讽除外）

**句子**
- [ ] 单句成段占比 ≥ 35%
- [ ] 一句话里没有两个"像是"
- [ ] "忽然"≤10/万字，"突然"≈0
- [ ] 感叹号密度符合所选模式（校园 10–18／第一人称 0–3／都市奇幻 15–70／史诗 30–55）
- [ ] 三种"江南句"各至少一次，但预叙句不超过两次

**人物**
- [ ] 每个人都填了四件套
- [ ] 遮住名字，仍能分辨谁在说话
- [ ] 至少一个人物**违反了自己的标签**（否则是卡通）
- [ ] 女性角色的"欲望栏"填得出来
- [ ] 主角的每一次选择都是他自己的，不是作者安排的

**结构**
- [ ] 结尾的形状在第 1 页就定了（错位重逢／迟到的真相／散场）
- [ ] **（同人）**称呼矩阵填完，每一格都有原作依据；群像场景里配角之间的称呼也核过
- [ ] **（同人）**全文搜过「师兄/师姐/师弟/师妹/学长/学姐」，逐条确认了说话人
- [ ] 装置出现三次，第三次不解释
- [ ] 刀的触发者是人物，不是意外
- [ ] 每一章都问过"主线推进了吗"

**剪裁**
- [ ] 删掉了所有"这是什么意思"式的解释段
- [ ] 删掉了所有作者注、括号百科
- [ ] 爽点之后没有立刻加总结

### 6.2 跑脚本

```bash
python scripts/style_check.py 你的稿子.txt --mode c   # c=都市奇幻, b=末日第一人称, a=校园, d=史诗
python scripts/style_check.py 你的稿子.txt --mode c --canon 楚子航,路明非,夏弥   # 同人：额外查称呼与届别
```

输出九项指标，并与四本基准对比，标出超配额的项目。

**读法**：脚本只测"形状"，不测"好坏"。指标全对但读起来假，说明**人物动机**出了问题，回去改 §4。

## 7. 不许做的事

1. **不许全员段子手**。幽默只属于两三个人，其余人要认真活着。
2. **不许解释自己的比喻**。比喻写完就停。
3. **不许用谜团替代情节**。新问题开得比旧问题快 = 烂尾预订。
4. **不许让主角靠"我特殊"赢**。赢要赢在人物选择和既定规则上。
5. **不许把女性写成奖品、人质或墓碑**。
6. **不许把同人的称呼、届别、专有名词写错**。写错不是瑕疵，是告诉读者「我不认识这些人」。
7. **不许把"惨"当成深刻**。惨要有因果，要有选择。
8. **不许注水**。一个篇章超过 12 章，回去砍一半。
9. **不许在后记里泄气**。作者自述会削掉正文的余味；要写就写得比正文更克制。

## 9. 一句话交底

**江南的所有技术，最后都指向同一件事：让读者先爱上一个人，再让他眼睁睁看着那个人因为自己的选择而失去。写不出来的时候，就问自己一句——这一段，我是在让他被爱，还是在让他付账？**
