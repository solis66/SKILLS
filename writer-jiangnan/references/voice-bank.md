# 声音库（voice-bank）

> 江南的每一本书，叙述者只有**一张脸、一套词、一个自我评价**。
> 这份文件给你四张现成的声音卡，和一张可以自己填的空卡。

---

## 一、四本书的叙述声音卡

### A · 此间的少年（全知说书人）

| 项 | 内容 |
| --- | --- |
| 自称 | **我们**（"而我们的故事，也是从那个时间和空间点上开始的"） |
| 与读者的关系 | 毕业多年的师兄，在学校门口跟你聊了四年 |
| 自我评价 | 自嘲但不自卑，略带怀旧的"我现在老了" |
| 三个口头禅 | "很久以后……"／"事实上……"／"说起来……" |
| 句子长度 | 中长（24 字中位数），从句多，插入语多 |
| 他绝不说 | "那是一个夏天"这类纯抒情；他一定接一句具体的事 |
| 标志动作 | 随时跳到未来（"很久以后，郭靖才明白……"），随时跳到史料（"据老生评定后给出的结论……"） |

**典型句**：
> "汴京大学嘉佑一届，生物技术系的杨康，就这么走进了我们的故事。"
> "很久以后，郭靖才明白这并不意味着汴京大学是个青春洋溢的地方。"

### B · 上海堡垒（第一人称自嘲限知）

| 项 | 内容 |
| --- | --- |
| 自称 | **我**；职业自称"算泡泡的"、"搞泡防御的" |
| 与读者的关系 | 一个在加班的技术员在跟你吐槽，顺手讲完了他的爱情 |
| 自我评价 | 怂、没眼色、八卦、不懂女人心 |
| 三个口头禅 | "我靠"／"其实"／"这算什么" |
| 句子长度 | 短（20 字中位数），单句成段占 47% |
| 他绝不说 | "我爱你"（只敢写在短信里，还删掉）；"我很痛苦" |
| 标志动作 | 用技术参数说情绪："其中有些灰是我的，有些是林澜的。" |

**典型句**：
> "我真的只是个算泡泡的，算不懂人心，尤其是女孩的心。"
> "听起来像是一条没事找事的骚扰短信，我输入完这四个字立刻把它们又删除了。"

### C · 龙族（第三人称限知，滑入自由间接引语）

| 项 | 内容 |
| --- | --- |
| 自称 | **他**（路明非），但句子里全是"我"的语气 |
| 与读者的关系 | 你就是他，正在被当众羞辱 |
| 自我评价 | 衰、怂、没本事、活该 |
| 三个口头禅 | "我靠"／"扯淡"／"师姐" |
| 句子长度 | 短句爆发 + 长句铺陈，两极分化 |
| 他绝不说 | 任何漂亮话；越是感动越是骂人 |
| 标志动作 | 不加"他想"、不加引号，叙述直接滑进心里 |

**典型句**：
> "其实生日什么的对路明非无所谓。谁会记得？叔叔婶婶？别开玩笑了。"
> "他清楚地知道这一次醒来，将不会看见阳光里天使低头。"

### D · 九州·缥缈录（第三人称限知 + 史书全知）

| 项 | 内容 |
| --- | --- |
| 自称 | **他**（吕归尘/姬野/息衍），另有一层**史官**的声音 |
| 与读者的关系 | 一个在四十五年后翻史书的人，在给你讲当年的事 |
| 自我评价 | 人物贬低自己（"我太自大了啊"）；史官不评价，只记录 |
| 三个口头禅 | "许多年之后……"／"其实"／"他并不知道……" |
| 句子长度 | 中（22 字），四字句与对仗穿插，感叹号密度 44/万字 |
| 他绝不说 | 现代词汇（除了极少数刻意的错置） |
| 标志动作 | 「历史」小节：用后世官史的口吻重述刚刚发生的事 |

**典型句**：
> "许多年之后，青阳昭武公吕归尘阿苏勒死在他金色的帐篷中。"
> "他们握了手，于是第一个人和第二个人就此相逢。霸业或者宿命，都由此开始。"

## 四、江南词库

**高频名词**（择用，不要全用）：血、雪、云、风、火、光、眼睛、天空、门、雨、夕阳、影子、道路、骨头、指尖、喉咙、胸口。

**高频动词**：攥、握、擦、按、垂、退、颤、咬、扑、渗、烧、沉、裂、响。

**高频形容词**（谨慎，江南本人也滥用）：苍白、滚烫、冰冷、沉重、安静、黑色、通红。

**禁用词**：励志、梦想（除反讽）、逆袭、正能量、蜕变、治愈、成长（作为主题词）、坚持就是胜利、破茧成蝶。

**慎用词配额**：

| 词 | 配额（每万字） |
| --- | --- |
| 忽然 | ≤10 |
| 突然 | ≈0（江南几乎只用"忽然"） |
| 仿佛 | ≤4 |
| 其实 / 原来 / 所谓 | 合计 ≤8 |
| 像是 / 好像 / 如同 / 似的 | 合计 5–25（按模式） |

## 五、三种开场与三种收尾的速查

**开场**

| 类型 | 首句模板 | 用在哪 |
| --- | --- | --- |
| 冷开场对话 | `"X 也会 Y 么？"／"难说，自己做好准备。"` | 末日、史诗 |
| 先声后形 | `他醒来听见的第一个声音是 X，满耳的 X，像是整个世界都在 X。` | 奇幻、悬疑 |
| 旁观者定时 | `又是 X 的秋天，积累了整整一个春夏的枝叶悄然凋零……` | 校园、回忆 |

**收尾**

| 类型 | 末句模板 | 效果 |
| --- | --- | --- |
| 错位重逢 | `"要我去弄点 X 么？"／"嗯，如果他们有的话。"` | 没得到，但还得活 |
| 迟到的真相 | 一件旧物 + 一个数字 + 不解释 | 读者自己完成情绪 |
| 散场 | `很快就有新的 X 们会从远处走来。` | 循环，不悲情 |
