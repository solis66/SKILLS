## 二、四个可以直接拿去用的结论

### 1. 单句成段 = 47%（第一人称模板）

《上海堡垒》近一半段落只有一句话。这是它"手机屏阅读"手感的来源。

**目标区间**：

| 模式 | 单句成段占比 |
| --- | ---: |
| B 末日第一人称 | 42–50% |
| A 校园回忆 | 38–43% |
| C 都市奇幻 | 30–48%（实测龙族 I = 32.2%） |
| D 东方史诗 | 32–38% |

### 2. 对话占比：史诗 35%，第一人称 20%

- 《缥缈录》35.6%：史诗靠**一群人开会**。
- 《此间》18.7%：喜剧靠**叙述者的嘴**。
- 《上海堡垒》20.3%：第一人称靠**独白**。

**目标区间**：A 16–26%｜B 18–30%｜C 26–44%（实测龙族 I = 36.6%）｜D 30–42%。

### 3. 感叹号是"音量旋钮"，模式之间差 24 倍

| 模式 | 感叹号（/万字） | 含义 |
| --- | ---: | --- |
| B 第一人称 | 0–2 | 这个人不喊 |
| A 校园喜剧 | 12–15 | 一群人咋呼 |
| D 史诗 | 40–45 | 军令、呼喝、誓言 |
| C 都市奇幻 | 15–70（实测龙族 I = 62.8） | 两极分化（日常低、战斗高） |

**这是最容易出错的一项**：把史诗的感叹号密度写进第一人称，会瞬间变成尬燃。

### 4. 比喻密度：抒情 29，喜剧 8

| 模式 | 比喻（/万字） |
| --- | ---: |
| B 抒情第一人称 | 25–30 |
| D 史诗 | 18–22 |
| C 都市奇幻 | 12–28（实测龙族 I = 21.3） |
| A 校园喜剧 | 5–10 |

**喜剧不靠比喻，靠错位。** 这是《此间的少年》全书只有 8.4 的原因。
