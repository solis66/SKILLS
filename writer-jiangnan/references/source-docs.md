## 二、四本各最值得抄走的三条

### 龙族（都市奇幻成长）

1. **衰小孩的限知视角**：用路明非的眼睛看世界，叙述语言就是他的内心语言。
2. **糖刀结构**：先建立可爱的日常，再把它夺走。
3. **神话日常化的混合语体**：龙、言灵、北欧神话、日本黑道、网络游戏、品牌混在一句话里，用一个人物的声音统一。

**最需警惕**：比喻依赖、谜团通胀、作者注、连载注水（V 的 235 章中 138 章叫"但为君故"）。

---

### 上海堡垒（末日第一人称）

1. **技术语言与情感语言并置**："其中有些灰是我的，有些是林澜的。"
2. **短信体叙事装置**：写—删—等—收件箱已满—迟到十二年的五个字。
3. **真实城市地名做记忆挂钩**：恒隆广场 = 那张失效的登机牌。

**最需警惕**：设定倾泻（第 10–12 节）、女主无欲望、后记泄气。

---

### 此间的少年（校园回忆体）

1. **借名法**：金庸的名字，作者朋友的性格；只借名字，不借命运。
2. **说书人全知腔**："而我们的故事，也是从那个时间和空间点上开始的。"
3. **四件套人物速写**：外号 + 身体 + 癖好 + 口头禅。

**最需警惕**：主线缺失、标签化、楔子过长（两千字二胡考据）。

---

### 九州·缥缈录（东方史诗）

1. **「历史」插叙**：在情节之间插入后世史书腔，给虚构世界颁发史实证书。
2. **预叙宿命**：在人物最天真时先写他的死。
3. **双文明语体**：用说话方式区分世界，不用设定表。

**最需警惕**：体积失控（200 万字收不回来）、口号磨损（"铁甲依然在"32 次）、女性缺席（她:他 = 1:8.9）。

## 三、四本共有的、跨作品的九个习惯

| # | 习惯 | 四本中的表现 |
| ---: | --- | --- |
| 1 | **用一个不勇敢的人做叙述者** | 路明非／江洋／郭靖／吕归尘 |
| 2 | **用一个物理装置承载情感** | 明信片／短信／二胡／豹尾 |
| 3 | **用一个精确的数字写时间** | "十二年九个月又六天"／"二百零七天" |
| 4 | **用一个"忽然"切换情绪** | 5.5–10 次/万字，四本一致 |
| 5 | **用动作代替情绪** | 擦手／删短信／画乌龟／磨刀 |
| 6 | **让强者平静** | 九王的酒香／将军的"滚蛋"／诺诺的"小弟" |
| 7 | **章末留一个未回答的问题** | 四本都有，密度不同 |
| 8 | **每本书都有一场"安静的高潮前夜"** | 空公寓／放映厅／浴缸／帐篷 |
| 9 | **结尾停在一句废话上** | 爆米花／出租车／新弦／"晚安" |

**这九条就是 writer-jiangnan 的内核**——比任何单本的技法都更接近"江南"。

## 四、四本的共同短板（也是这个 skill 强制纠偏的地方）

1. **女性角色工具化**：四本书全部中招，从林澜到羽然到绘梨衣。
2. **解释过度**：好场景之后总要加一段说明。
3. **中段塌陷**：长篇尤其明显（缥缈录卷三卷四、龙族 V）。
4. **自我重复**：句式、比喻、金句在四本之间反复出现。

**对应修正**见 `anti-patterns.md` 的 A6 / A2 / A10 / A9。
