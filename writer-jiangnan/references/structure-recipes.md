# 结构配方（structure-recipes）

> 三档篇幅的骨架、节拍表、以及每档必查项。

---

## 一、3000 字短篇（最稳的模板）

| 步 | 内容 | 字数 | 技法 | 检查点 |
| ---: | --- | ---: | --- | --- |
| 1 | 冷开场 / 一句对话 | 150 | T19 / 冷开场 | 不解释、不铺垫、不加"他心想" |
| 2 | 日常世界 + 两个人的关系 | 900 | T12 四件套 + T18 减压阀 | 糖：一个怪癖 + 一件便宜的东西 + 一段无用的日常 |
| 3 | 装置第一次出现 | 50 | T10 | 不显眼，读者会忽略 |
| 4 | 一件小事打破日常 | 600 | T26 钩子 | 危机看起来很小 |
| 5 | 选择 | 400 | T13 动作代替台词 | **人物自己选错**，不许是意外 |
| 6 | 刀 | 600 | T25 糖刀 | 失去；触发者是人物 |
| 7 | 装置第三次出现 | 150 | T10 | **不解释** |
| 8 | 日常台词收尾 | 80 | T28 错位重逢 | 一句关于吃喝的废话，把镜头移开 |

**总账**：糖 1100 字 / 刀 1200 字 / 收尾 230 字。

**最容易犯的错**：第 5 步让"意外"替人物做决定。**必须是他自己伸手去够那个东西。**

## 二、8000 字短篇

在上面基础上做两次拆分：

- 第 2 步拆成两场：**一场给关系**（两个人的日常），**一场给世界**（他们所处的困境）。
- 第 6 步拆成两场：**一场给事件**（事情发生），**一场给余震**（别人怎么继续活）。

| 段落 | 内容 | 字数 |
| --- | --- | ---: |
| 1 | 冷开场 | 200 |
| 2a | 关系日常（糖） | 1400 |
| 2b | 世界日常（糖的背面） | 1200 |
| 3 | 装置第一次 | 60 |
| 4 | 小事打破日常 | 1200 |
| 5 | 选择 | 900 |
| 6a | 刀：事件 | 1200 |
| 6b | 刀：余震 | 900 |
| 7 | 装置第三次 | 200 |
| 8 | 收尾 | 120 |

**8000 字的额外要求**：至少要有一个**次要人物**做了主角不敢做的选择，用来给主角照镜子。

## 三、中篇（3–8 万字）

**骨架：三幕 + 一个装置**

| 幕 | 内容 | 占比 |
| --- | --- | ---: |
| 第一幕 | 建立日常世界 + 一个改变 | 25% |
| 第二幕 | 试错、组队、第一次失败 | 50% |
| 第三幕 | 选择、代价、收束 | 25% |

**中篇专属节拍**（江南最常用的那一种）：

```
日常／搞笑 → 亲密／暧昧 → 小危机 → 解决／发糖 → 更大的危机 → 失去 → 迟到的真相 → 余震
```

**中篇必查**：
- 中点有没有一次反转？（以为是 A，其实是 B）
- 主角在中点之后，目标有没有变？
- 有没有一个"安静的场景"放在高潮之前？（江南每次都放：空公寓、浴缸、电影放映厅）

## 四、长篇（20 万字以上）

### 4.1 三级结构

```
卷（5–8 卷）
 └ 幕（每卷 5–10 章）
    └ 节（每章 3–6 节，每节 2000–4000 字）
```

**总量控制**：一卷 15–30 万字，一节 2000–4000 字，一章 8000–15000 字。

### 4.2 单卷模板（江南的史诗节拍）

| 步 | 内容 | 任务 |
| ---: | --- | --- |
| 1 | 冷开场 / 「历史」小节 | 宣布这一卷的时代背景（T5） |
| 2 | 一个陌生的场面 | 先声后形，主角还不在场（T19） |
| 3 | 主角登场 | 笨拙、被保护、什么都不懂 |
| 4 | 势力陈列 | 主君、名将、谋士、使节，一人一段军议（T15） |
| 5 | 第一次流血 | 一场近身暴力特写（T20，全卷只此一次） |
| 6 | 离别 | 一句誓言 + 一件器物（T16 + T17） |
| 7 | 时间跳跃 | 几年后，孩子长大了 |
| 8 | 大场面 | **一个视觉上独一无二的高潮场面** |
| 9 | 代价 | 一个有名有姓的人死了 |
| 10 | 「历史」小节 | 把这一卷写进历史（T5） |

### 4.3 系列级的三条保险（防江南式"收不回来"）

1. **每卷回答一个局部问题，只开一个新问题。**
   - 开工前列一张表：`第 N 卷｜回答：___｜新开：___`
   - 如果新开的比答的多，砍。

2. **给主角一个倒计时的代价。**
   - 每用一次力量，就失去一样东西（寿命、记忆、身边的人）。
   - 这个倒计时必须在**第一卷**就启动。

3. **先写讣告，再写生平。**
   - 列一张人物名单，标上"必须在第几卷退场"。
   - 每个人的退场理由必须写一句话：他因为**自己的什么选择**而死。

### 4.4 长篇的四本必填表

**表一 · 声音卡**（见 voice-bank.md）

**表二 · 人物退场表**

| 人物 | 退场卷 | 退场理由（他自己的选择） | 留下的东西 |
| --- | --- | --- | --- |
| | | | |

**表三 · 装置表**

| --- | --- | --- | --- |
| | 第 __ 章 | 第 __ 章 | 第 __ 章 |

**表四 · 谜团账本**

## 五、章内节拍（所有篇幅通用）

一章 = 3–6 节，每节走一遍这个微结构：

```
一个感官/动作的开头（1–3 句）
  ↓
一个信息（可以是对话、可以是景物）
  ↓
一个小转折（人物的判断被推翻，或者环境变了）
  ↓
一个选择/反应（人物的动作）
  ↓
一个收束（一句短话，或一个钩子）
```

**每节只做一件事。** 一节里塞两个事件 = 两个事件都做不深。

## 六、结尾的三种形状（选一个，先写出来）

| 形状 | 结构 | 例 |
| --- | --- | --- |
| **错位重逢** | 迟到的真相 → 独处 → 撞见另一个人 → 一句日常台词 | 上海堡垒结尾 |
| **迟到的真相** | 一件旧物 → 一个数字 → 不解释 → 停 | 登机牌 |
| **散场** | 送别 → 回到原点 → 新人从远处走来 | 此间的少年结尾 |

**三条禁忌**：
1. 不许痛哭独白
2. 不许"我终于明白了"
3. 不许用死亡收束最后一段

---

## 七、开工前的五项决策（写下来，不要在心里过）

```
1. 模式：A / B / C / D（可杂交两个）
2. 体量：___ 字
3. 叙述者的自我评价：___（必须是贬低的）
4. 装置：___（一件，出现三次）
5. 结尾的形状：___（先写 50 字）
```

**五项填完才动笔。** 填不出来的，写出来一定塌。
