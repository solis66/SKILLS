# 手法库（technique-library）· 30 手

> 三十个手法，覆盖江南四部作品里**推进叙述、塑造人物、控制节奏**的全部可复用动作。
> 每一条给：**定义 / 动作 / 例句 / 参数 / 失效条件**。
>
> 参数来源：四本书的全文统计（见 `corpus-stats.md`）。

---

## 第一组 · 视角与叙述距离（1–5）

### T1 自嘲限知视角

- **定义**：叙述者不高于人物；叙述语言使用人物的词汇、判断和自嘲；没有"他想"，但整段都是他的想法。
- **动作**：
  1. 给主角一个**贬低的职业自称**（算泡泡的、死小孩、我这种人）。
  2. 让他**只看得见他看得见的**——不写全景，只写他目力所及。
  3. 每当他差点说出漂亮话，就让他自己拆台。
- **例**：`"我真的只是个算泡泡的，算不懂人心，尤其是女孩的心。"`
- **参数**：第一人称密度"我"250–300/万字（《上海堡垒》299.3）。
- **失效**：单向度、自怜；全书只有一个声道时，读者会腻。

### T2 自由间接引语

- **定义**：把人物的话直接嵌进叙述，不加引号，也不加"他想"。
- **动作**：写一段第三人称叙述，中间忽然出现**只有人物会用的词**（方言、脏话、外号），不加标记。
- **例**：`"谁会记得？叔叔婶婶？别开玩笑了。爹娘？那是相当不靠谱。"`
- **参数**：一段最多两处，超过就变成意识流。
- **失效**：叙述者与人物界限模糊；人物不可爱时，反讽会变刻薄。

### T3 认知翻转

- **定义**：先建立一个预期，再用一个词把它翻过来。
- **句式**：`其实 X。／原来 X。／所谓 X，就是 Y。`
- **例**：`"所谓伟大的忍术传统，本来就是一场骗局。"`／`"原来诺诺跟陈雯雯是一模一样的。"`
- **参数**：**3–8 次/万字**（四本实测：此间 4.4、缥缈录 3.2、上海堡垒 7.7、龙族 7–8）。
- **失效**：套路化；每段都"其实"，读者会预判。

### T4 预叙宿命

- **定义**：在人物最天真时，先写他的结局。
- **句式**：`许多年之后，X 死在 Y。／很多年以后，X 才明白……／他不知道，这是他最后一次……`
- **例**：`"许多年之后，青阳昭武公吕归尘阿苏勒死在他金色的帐篷中。"`
- **参数**：**一部作品两次**：一次主角结局，一次关系结局。
- **失效**：剧透癖；用第三次就变套路。

### T5 史书插叙（"历史"小节）

- **定义**：在情节之间插入后世史官口吻的段落，把刚发生的事写进历史。
- **动作**：
  1. 造一部**虚构史书**的名字（《燮河汉书》）。
  2. 用四字句、对仗、文言节奏写三段：局势、事件、评价。
  3. 最后落一句**当事人的小事**，让宏大和具体撞一下。
  4. 回到当下情节，不解释。
- **例**：`"是时，天地为熔炉，万物为薪炭，血泪并煎于其中。"`
- **参数**：**每卷 2–3 次，每次 ≤800 字**，只在卷首／卷末／重大伤亡后。
- **失效**：结构割裂、上帝视角泄漏、变成设定集。

## 第二组 · 句子与节奏（6–11）

### T6 短句爆发 + 长句铺陈

- **定义**：情绪高潮用短句短段；说明/世界观用长句。
- **动作**：高潮段的句子砍到 6–12 字，段落砍到 1–2 句；说明段可以到 60–120 字。
- **例**：`"……Sakura……Sakura……Sakura!"` vs 东京塔之战的长句军事报告。
- **参数**：**单句成段占比 ≥35%**，第一人称可到 47%。
- **失效**：长句信息过载；短句滥用导致碎片化。

### T7 排比 / 反复 / 呼告

- **定义**：重复一个词、名字或句式，把散文变成咒语。
- **例**：`"不要死，不要死不要死……不要死！"`／`"刺穿黑暗的光，刺穿宇宙的变形金刚，刺穿时光的克赛号……"`
- **参数**：**只在情绪最高点用一次**；重复的必须是**具体的词**（名字、动作），不是抽象口号。
- **失效**：煽情、重复磨损。

### T8 假设式排比抒情

- **定义**：在情绪高点，用一连串反问和假设把句子推上去。
- **例**：`"说了那个后果你怕不怕？你要去抓她的手么？也去抓她的任性她的眼泪她的理想她的初恋情人……"`
- **参数**：四到六问，然后**立刻收住**。超过六问就是失控。
- **失效**：句子膨胀；问句连击会读成嚎叫。

### T9 精确的时间锚

- **定义**：给情绪配一个精确到天的数字。
- **例**：`"不记得过了多久，我拿出一张纸，做了一个简单的减法，是十二年九个月又六天前。"`
- **参数**：一部作品 3–5 次；**每次都必须跟着一个"计算"的动作**（减、数、看表）。
- **失效**：数字堆砌成考试题。

### T10 物件接力（物件抒情）

- **定义**：不写"他难过"，写他怎么处理一件东西。
- **动作**：
  1. 选一件**便宜的、旧的、有磨损的**东西。
  2. 让它出现三次：日常 → 有了意义 → 全部意义压上来。
  3. 第三次**不解释**，紧跟一句日常台词把镜头移开。
- **例**：`"那双带白色毛边的靴子，其实我买了的，前些天他们把原来的宿舍打开了，靴子还在那里。"／"早都不流行了啊。"／"不过我还是要！"`
- **参数**：一部作品**一件主装置**，最多两件。
- **失效**：物件清单化；每件都"刚好"有意义 = 设计感过重。

### T11 反高潮吐槽

- **定义**：在最该肃穆的地方插一句没正形的话，把情绪从悬崖边拽回来。
- **例**：`"我想这个记者也太过八卦了，我身上从头到脚清楚地说明了我是干什么的。"`
- **参数**：**悲壮场景之后可以吐槽；真正的情感高点不许吐槽**（江南在林澜之死处没有吐槽，这是正确的判断）。
- **失效**：用错位置会情绪断电。

## 第三组 · 人物（12–18）

### T12 四件套速写

- **定义**：外号 + 身体 + 癖好 + 口头禅，四样凑齐，人物立刻可辨。
- **例**：乔峰＝"土匪"+一米九五+课本画乌龟+"很猛"。
- **参数**：**每个出场人物都要有**；主角可以少一样（留给弧光）。
- **失效**：标签化；一个人只有四件套就只是卡通。

### T13 动作代替台词

- **定义**：写少年的窘迫、暗恋、自卑，不给他台词，给他动作。
- **例**：`"许久，姬野把手心在自己的胸口上擦了一下，伸出去，羽然握住了。"`（穷孩子怕自己手脏）
- **参数**：一段最多一个关键动作；动作必须**无意义**（擦手、扶眼镜、掏口袋），不许是"他握紧了拳头"这类陈词。
- **失效**：所有少年都用同一套动作（搓手、低头、说不出话），人物同质。

### T14 让强者平静

- **定义**：越是残忍的决定，越要用温和的句法说出来；让旁观者的感官和强者不一致。
- **例**：`九王抽动鼻子，像是闻着馥郁的酒香……／比莫gān 愣了一下，风里只有浓重的灼烧气息和血腥味。`
- **参数**：**每个反派至少一次**。
- **失效**：反派魅力盖过主角；"微笑的阴谋家"是类型模板。

### T15 双文明 / 双层语体

- **定义**：用**说话方式**区分世界、阶层、时代，不用设定表。
- **动作**：给每个群体固定三样——称呼系统、句长、专属器物。
- **例**：蛮族短句+天神；东陆长句+典故。将军短句+脏话；技术员长句+参数。
- **参数**：**最多两套**；三套以上读者会迷路。
- **失效**：设定负担；前 50 页门槛高。

### T16 誓言母题

- **定义**：给全书设一句可复用的誓言，在不同时间点以不同方式重演。
- **动作**：立誓（全句）→ 误解（半句）→ 背叛（被引用错）→ 重述（别人替他说）→ 遗言（最后给全句）。
- **例**：`"我会保护你的。"／"铁甲依然在！"`
- **参数**：**一部作品最多五次**。
- **失效**：口号磨损；第十次之后变成背景音。

### T17 器物传记

- **定义**：给人物绑定一件器物，并完整讲述它的来历。
- **例**：虎牙枪的来历 → 姬野的身世 → 天驱的信仰。
- **参数**：**一人一物**，超过两件就合并。
- **失效**：变成装备表；每件都要写来历，会造成说明性插叙。

### T18 群像的减压阀

- **定义**：设一个 3–4 人的小团体，用外号 + 共同爱好 + 互损建立日常，专门在紧张段落里让人笑。
- **例**：大猪、二猪、苏婉的《帝国时代II》杀猪战术。
- **参数**：**其中至少一个人的命运必须和主线绑定**，否则读者会觉得白读了。
- **失效**：闲笔过长，主线停滞。

## 第四组 · 场景与细节（19–24）

### T19 感官开篇（先声后形）

- **定义**：小节开头不写"他走进来"，先给一个感官碎片，再对上人。
- **例**：`"阿苏勒醒来听见的第一个声音是水声，满耳的水声，像是整个世界都在下雨。"`
- **参数**：一卷最多用三次，否则形成固定节拍。
- **失效**：读者能预判下一节怎么开头。

### T20 暴力特写（精确到解剖）

- **定义**：不写招式，写后果，精确到骨头、血、体温。
- **例**：`"清楚地感觉到自己的剑切入了人体，斩开背骨，又直推了进去。"／"那上面龙格沁的血还是暖的。"`
- **参数**：**一场战役只写一次**，其余全部用远景（"刀光中人像砍草般倒下"）。
- **失效**：血腥过密会麻木；滑向虐杀美学。

### T21 真实地名 / 行业细节

- **定义**：用真实可查的地名、品牌、制度、硬件造现实感。
- **规则**：**每一个地名后面必须挂一个人或一件事**。挂不上的删。
- **例**：恒隆广场 = 那张失效的登机牌；梅龙镇 = 空荡的商场和米老鼠灯箱。
- **参数**：品牌只用来做"人物/阶层的速写"，不要用来做作者的知识展示。
- **失效**：广告感、过时、知识炫技、打断叙事。

### T22 大段风物

- **定义**：在紧张情节之间插入关于吃、穿、住、猎的民俗描写。
- **例**：`"他跟着英氏夫人帐篷里的女奴们剥了一下午的旱獭……烤起来有种细腻的脂香，一咬满嘴都是油。"`
- **参数**：**每卷不超过三处**，且必须挂在人物的饥饿/寒冷/受伤上。
- **失效**：节奏拖、民俗百科。

### T23 都市传说做转场

- **定义**：用一则有两个互相矛盾版本的校园/地方传闻，把两个场景接起来。
- **例**：二教的鬼自习；半夜卖饭票的女鬼。
- **参数**：一章最多一次。
- **失效**：与主线脱节，变成怪谈合集。

### T24 伪史料腔

- **定义**：给毫无意义的小事配一套学术/史料式的说明。
- **例**：`"据老生评定后给出的结论，能娶康敏就直接进入小康生活了，所以她也叫小康。"`
- **参数**：喜剧模式专用；连续三段会疲劳。
- **失效**：作者在表演聪明。

## 第五组 · 结构与情感工程（25–30）

### T25 糖刀结构

- **定义**：先给可爱的日常，再把它夺走。
- **动作**：
  1. 给角色一个**可爱的怪癖** + 一件**便宜的东西** + 一段**无用的日常**。
  2. 让读者放松到"这书其实挺轻松"。
  3. 在读者最放松时夺走。
  4. 用物件和迟到的真相补刀。
- **例**：绘梨衣的玩具与明信片 → 红井；夏弥的空公寓与钥匙 → 耶梦加得。
- **参数**：3000 字短篇 = 糖 1800 / 刀 800 / 补刀 400。
- **失效**：可预测；女性工具化；读者感到被操纵。
- **江南自己的说明书**：`"喜剧中欢乐是为了让人笑，而悲剧中的欢乐是为了让人在结尾时的悲伤加倍。"`

### T26 章末钩子（三种，不许发明第四种）

1. 一个未回答的问题（人物说了半句话）
2. 一个突然出现的人 / 物
3. 一句预叙（"他没想到，这是他最后一次看见她。"）
- **参数**：**一章最多一个**。
- **失效**：每章都断在刀口上 = 悬念通胀。

### T27 多视角 + 媒介插入

- **定义**：主视角之外，用切镜和媒介（论坛帖、短信、日记、新闻、监控回放、聊天记录）扩大世界。
- **例**：守夜人讨论区；Line 聊天；手机短信；官史。
- **参数**：**每三章最多一次**媒介插入，且必须推动主线或揭示人物。
- **失效**：悬念泄漏、碎片化、信息倾倒。

### T28 错位重逢收尾

- **定义**：主角没得到他想要的，但撞上一个必须继续活下去的日常瞬间。
- **例**：`"要我去弄点爆米花么？"／"嗯，如果他们有的话。"`
- **参数**：**一部作品一次**，放在最后一页。
- **失效**：情感账没算清；读者会觉得"这就完了？"——所以前面必须已经给过"迟到的真相"。

### T29 现代科技做叙事装置

- **定义**：把手机、短信、录音、监控做成情节装置，而不是道具。
- **动作**：写 → 删 → 等 → 误响 → 容量限制 → 迟到。
- **例**：`"您有一条新的短消息，您的收件箱已满，请先删除不必要的短消息。"`
- **参数**：**最多三个节点**（第一条未发、中间一条误发、最后一条迟到）。
- **失效**：重复、刻意。

### T30 标题与包装（诗化 + 双语 + 引语）

- **定义**：卷名诗化、章名双语、章首引语、古典用典。
- **例**：火之晨曦／悼亡者之瞳／黑月之潮；"但为君故"取自曹操《短歌行》。
- **参数**：**包装必须兑现**——标题许诺的宏大，正文要给得起。
- **失效**：包装大于内容；用典过多显得端着。
