# 同人创作的「原作一致性」检查表（canon-fidelity）

> **一句话内核**：文笔像江南，只能让读者觉得「写得像」；
> **人物关系对不上，读者第一句就会出戏**——而出戏是不可逆的。
>
> 同人读者是**带着原作记忆来读的**。他们记得谁叫谁师兄、谁比谁高一届、
> 谁是上一任会长、谁死在第二部。这些不是背景设定，是**读者的条件反射**。
> 你写错一个称呼，他不会觉得「作者搞错了」，他会觉得「这不是那个人」。

---

## 0. 什么时候必须读这份文件

| 任务 | 是否必读 |
| --- | --- |
| 写**同人**（有原作人物/世界观） | **必读，且必须先做 §1 的抄录** |
| 写**原创**（自己的人物） | 不用，但 §3 的「称呼决定亲疏」仍然通用 |
| 改编 / 续写 / 平行线 | 必读，且 §4 的「改动清单」要写给读者看 |

**如果原作你只记得个大概——不要动笔，先做 §1。**

---

## 1. 第一步：抄录，不是回忆（硬性动作）

**回忆会骗人，抄录不会。** 动笔前，从原作（或可靠的原作资料）里**抄下来**这五样，写在一张纸上，贴在文档开头：

```
1. 人物名单（含：全名 / 别人怎么叫他 / 他叫别人什么）
2. 届别与身份（谁比谁高一届、谁是谁的师兄、谁的导师、谁是会长）
3. 只有原作有的东西（言灵名、武器名、组织名、地名、专有名词的写法）
4. 时间线（这件事发生在第几部、之前发生过什么、之后会发生什么）
5. 当前状态的边界（这个时间点上，谁还活着、谁还不知道真相）
```

**抄录的铁律：**

- **不确定的，标「待核」，不要用「大概是」填。** 一个错的名字比一个空的名字伤害大得多。
- **不要用同人（包括二创、动画、手游、他人同人）反推原作。** 二次设定会污染你的判断。
- **不要把「我记得」当成「原作如此」。** 记忆里最鲜活的那个细节，往往正是被同人改过的那个。
- **抄的时候连标点一起抄。** 专有名词的破折号、间隔号、异体字，改一个字都刺眼。

## 2. 称呼矩阵（**最容易出错、也最伤读者的一处**）

### 2.1 称呼不是礼貌问题，是**关系坐标**

同一句台词，换个称呼，人物关系就变了：

| 写法 | 读者读到的关系 |
| --- | --- |
| 「师兄，你觉得他怎么样？」 | 她比他低一届，或者她是他的直系后辈 |
| 「师弟，你觉得他怎么样？」 | 她比他高一届 —— **如果原作里她是师妹，这句就废了** |
| 「楚子航，你觉得他怎么样？」 | 平级、亲近、或者她根本不服这个辈分 |
| 「楚学长，你觉得他怎么样？」 | 疏远、客气、或者故意拉开距离 |

**所以：改称呼，就是在改人物关系。反过来，写错称呼，就是写错了人物关系。**

### 2.2 画一张矩阵，逐格填

```
          │ 楚子航        路明非        夏弥
──────────┼────────────────────────────────
楚子航 叫 │ —            明非          夏弥
路明非 叫 │ 师兄          —             师妹
夏弥   叫 │ 楚子航/师兄   师兄          —
```

**填法规矩：**

1. **只填原作给过的称呼。** 原作没给过的格子，填「无」，不要自己发明。
2. **横轴是「被叫的人」，纵轴是「叫的人」。** 每一格都必须单独确认，**不能推**。
3. **「他叫我什么」和「我叫他什么」不对称是常态。** 夏弥叫楚子航全名、路明非叫楚子航师兄，这两件事同时成立——不对称本身就是人物关系的一部分。
4. **称呼会随场景变。** 正式场合 / 吵架时 / 生死关头，同一个人可能换称呼。这种切换是**免费的戏**，但要建立在一个稳定的默认称呼之上。

### 2.3 四个高频雷区

| 雷区 | 症状 | 为什么会错 |
| --- | --- | --- |
| **届别反了** | 把师妹叫成师姐 | 写的时候只想着「她看起来像姐姐」 |
| **推错了** | 由「楚是他师兄」推出「她是他的师弟」 | 两个人的届别差**不是传递关系**，必须分别查 |
| **跟着感觉走** | 谁气场强，谁就被叫「师兄」 | 称呼由**入学年份/入门顺序**决定，不由气场决定 |
| **跨作品串味** | 把 A 作的称呼习惯搬进 B 作 | 同一个作者的两本书，辈分系统可能完全不同 |

> **特别提醒（最隐蔽的一类）**：如果你写的是**群像场景**（三个人以上），那么**每一对人之间**都有一格要填。三个人的场景有 6 格，四个人有 12 格。群像戏里称呼写错，往往不是主角那一格错，而是**配角之间**那一格错。

## 3. 让称呼替你干活（不只是「别写错」）

称呼对了之后，它是**最省字的人物技术**——一个称呼就能交代三层信息：

1. **层级**：师兄/师妹/学长/教官/会长
2. **亲疏**：全名（亲近或疏远，看语气）／外号（只有熟人能用）／敬称（故意拉开）
3. **此刻的情绪**：平时叫全名的人，忽然叫了一声「师兄」，那是**服软**；平时叫「师兄」的人，忽然叫了全名，那是**翻脸**。

**用法：**

- 想写「她终于认了他这个师兄」，不要写心理活动，**让她改口叫一次**。
- 想写「他们已经生分了」，不要写「两人之间有了隔阂」，**让对方把称呼换回敬称**。
- **改口必须只发生一次。** 用两次就变成廉价煽情（同 §4.4 的女性纠偏）。

> 江南自己的写法：称呼常常是**固定不变的**，情绪靠句长和答非所问来写。所以「改口」这一手要省着用——**一部短篇最多一次**。

## 4. 改动的边界：哪些能改，哪些不能

同人必然会改。问题是**改在哪里**。

| 层级 | 能不能改 | 说明 |
| --- | --- | --- |
| **称呼 / 届别 / 身份** | **不能改** | 改了就不是同人，是借用名字的原创。读者第一页就会退出 |
| **专有名词写法**（言灵、武器、组织） | **不能改** | 错一个字都刺眼。抄录时逐字核对 |
| **人物性格内核** | 不能改，但**可以加层次** | 让他在一个原作没写过的场景里做他「会做的事」 |
| **已发生的事件** | 不能改，除非你明说这是平行线 | 见下 |
| **未写明的空白**（他当时在想什么、那天晚上她去了哪） | **随便改** | **这是同人唯一真正自由的地方，也是最值钱的地方** |
| **新增配角 / 新增支线** | 可以，但不能抢主线 | 新人物不许解决原作人物解决不了的问题 |

**平行线（AU）的正确做法：**

- 在**开头或简介**用一句话交代「从哪一点开始不一样」，别让读者自己猜。
- 只改**一个**变量。改两个以上，人物动机就会跟着变，人物就不再是那个人。
- 改了结局，就要**重新结账**：原作的「刀」消失了，你得另找一把刀，否则故事会变成发糖——而江南的读者不是来吃糖的。

## 5. 发稿前：同人专项自查（在 §6.1 十六条之外）

- [ ] 五样抄录（名单/届别/专名/时间线/状态边界）都写在文档开头了
- [ ] 称呼矩阵填完了，**每一格都来自原作**，没有推出来的格子
- [ ] 群像场景里，**配角与配角之间**的称呼也核对过
- [ ] 专有名词逐字核对过（不是「差不多」，是逐字）
- [ ] 时间点上「谁还不知道真相」核对过——**让不知道的人说了知道的话，是最致命的错**
- [ ] 改动清单写了：改了什么、从哪一点分叉、为什么
- [ ] 全文搜一遍「师兄/师姐/师弟/师妹/学长/学姐」，**逐条确认说话人是谁**

> 最后一条是**机械动作，但救命**。写作者在长文里最容易犯的错，不是不懂关系，而是**写到第三千字时忘了谁是谁**。

## 6. 案例：一次真实的翻车（楚子航 / 路明非 / 夏弥）

**原作关系**：楚子航比路明非高一届，路明非比夏弥高一届。所以楚子航是两人的师兄，夏弥是路明非的**师妹**。

**写错的版本**：

> 「师弟，你觉得楚子航这个人怎么样？」（夏弥对路明非说）
> 「师姐，你为什么老是要排名啊。」（路明非对夏弥说）

**错在哪**：

1. 夏弥叫路明非「师弟」—— 她比他低一届，这一句把她写成了学姐。
2. 路明非叫夏弥「师姐」—— 同一个错误的反面，两处互相印证，读者立刻发现。
3. **更麻烦的是**：这两句错得「很顺」，因为夏弥平时气场强、说话像个姐姐。**气场不是届别。** 这正是 §2.3 的「跟着感觉走」。

**改对的版本**：

> 「师兄，你觉得楚子航这个人怎么样？」（夏弥叫路明非「师兄」）
> 「师妹，你为什么老是要排名啊。」（路明非叫夏弥「师妹」）

**顺带修好的一处**：如果读者不知道三人届别，光改称呼还不够——补一句交代，让称呼有根：

> 按届别算，楚子航比路明非高一届，路明非比夏弥高一届。可夏弥从来不叫他师兄，她叫全名，一个字一个字地叫，像在点名。

**为什么这一句值得写**：它同时做了三件事——交代了层级、解释了「为什么她叫全名」、并且把这个不对称变成了人物性格。**这就是 §3 说的「让称呼替你干活」。**

## 7. 三十秒版

```
写同人之前，先做三件事：
1. 抄（不是回忆）五样：名单、届别、专名、时间线、状态边界
2. 画称呼矩阵，每一格都要有原作依据
3. 发稿前搜一遍所有称呼词，逐条确认说话人

写错称呼不是「小瑕疵」，
是告诉读者：写的人不认识这些人。
```
