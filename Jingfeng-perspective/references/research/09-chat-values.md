# 09 · 聊天中的价值观、决策与情绪

> 本维度补的是这个 skill 最大的窟窿：**以前全部语料里真正的"对话"只有「你好」两个字**。现在有 16 个会话、55,485 条、跨 2024-03-22 ~ 2026-10-25 的真实聊天。
> 统计口径：python 逐行 json.loads，脚本逻辑写在正文可复算处。所有引用格式为「文件#L行号」，行号=该 jsonl 内从 1 起算的行号。
> 隐私处理：第三方一律改称关系（妈/姐/小舅…）；金额、手机号、住址、病历、身份证一律不写；引用原话 ≤15 字。下文「同学A」~「同学H」是 8 个不同会话对象的编号，仅用于区分，不含身份信息。

## 1. 一句话结论

**在 AI 面前他是指令的作者，在熟人面前他是 5 个字的回应者。** 27,745 条文本消息中位长度 **5 字符**，88.4% ≤10 字符，98.3% 没有句末标点；他没有把对 AI 那套「口径、证据、行号」带进生活，但他把同一套东西的**底层脾气**带进来了：先砍再加、不装懂、给别人交的东西必须能验收、自己的事可以无限拖。

## 2. 说话方式：与 03-expression-dna 的断层

### 2.1 他不是"话少"，是"句子短、条数多"

| 指标 | 聊天（n=27,745） | 对 AI（n=171，见 03） |
|---|---|---|
| 中位长度 | **5 字符** | 35 字符 |
| ≤10 字符占比 | 88.4% | 30.4%（≤20 字符） |
| >100 字符 | 0.3% | 5.3% |
| 无句末标点 | 98.3% | 85.4% |
| 感叹号 | 30 条（0.11%） | 0 |

**连发节奏**：按 90 秒窗口合并，他共发出 9,801 段，平均 **每段 3.33 条**，63.3% 的段是多条连发，最长一段 162 条连续消息。也就是说——**他"长句不靠句号靠逗号"（03 §1.4）这件事，在聊天里变成了"一个想法拆成 3~5 条 5 字短句打出去"**。同一件事，两种载体。例：同学A#L6714-L6716「文档我写的出来就干他这个 / 写不来我就撤 / 我订个下周二回家的票」——一个决定拆成三条，第三条才落到动作。

### 2.2 最高频的那条消息是一个问号

- 纯「？」/「?」单独成条 **229 次**（占全部文本消息 0.83%）；含问号的共 433 条（1.56%）。
- 高频短消息 Top：「？」229、「[流汗]」144、「ok」136、「行」135、「666」125、「[捂脸]」110、「来」110、「👌🏻」109、「不知道」101、「可以」85、「没事」85、「是的」79。
- 「嗯」全语料只有 **2 次**——他不做语气承接。默认回应是「行 / ok / 可以 / 没事 / 是的」，遇到不理解就一个「？」。这不是冷淡，是他把"确认收到"和"要求补充"压到了最小字符数。

### 2.3 表情是他的句子，不是装饰

方括号表情 1,192 处、92 种。前五：流汗 145、捂脸 120、失望 76、合十 56、恐惧 56。

- **负面情绪几乎全部由表情承担**：失望 76、恐惧 56、流泪 25、发怒 20、叹气 17、尴尬 12、发抖 12、皱眉 11。
- 表情常单独成条替代整句话：妈#L1842 一整条就是「[失望]」；同学A#L3015 一整条是「[大哭]」。
- **「[合十]」是他的讨要/道谢专用**：妈#L6「给点钱花呗[合十]」、爸#L366 报班请求配[疑问]。

### 2.4 礼貌词：不是没有，是分人

|---|---|---|
| 小舅（长辈） | 3 / 23 | **13.0%** |

| 阿勇叔（长辈） | 1 / 23 | 4.3% |
| 爸 | 7 / 369 | 1.9% |

全语料「谢谢」69 条、「对不起」30 条、「辛苦」9、「麻烦」10。**「谢谢 0 次」只对 AI 成立，对人成立，对长辈最重。** 他对长辈用完整客套（「好的麻烦勇叔了」「辛苦阿勇叔」「谢谢小舅」），对同辈用「谁跟谁」（姐#L4914）。

## 3. 逐一检验 M1–M6

判定标准：**支持**＝聊天里有行为等价物；**不可观测**＝词汇与行为都找不到；**反例**＝聊天里出现相反行为。

| 模型 | 判定 | 聊天里的证据 |
|---|---|---|
| **M1 可指认性裁决** | **不可观测（仅 1 次）** | 全语料「行号」0、「逻辑」0、「核实」0、「实测」0；「证据」1 条：「我要看到证据」[同学H#L3075]，且是讨要东西的玩笑语境。「截图」9 条全是办事（要答案、要凭证），不是查证 |
| **M2 负向证据记账** | **机制不迁移 / 底层迁移** | 「负向证据」「未测」0 条。但 **「不知道」281 条（1.01%）**、「不知道啊」24、「没」23——不装懂的脾气原样搬过来了，只是不再记账 |
| **M3 口径先于数值** | **强迁移 2 次，语义变形** | ① 妈#L1509「我们口径不统一了」——**口径在这里指"对外的说法要一致"**，不是测量口径；② 爸#L653「注意是美元单位阿」——给父亲翻译报价单时主动标注单位。这是 31 个月里仅有的两次 |
| **M4 诊断/执行分离** | **无样本** | 「先不要」「先别改」全语料 0 次。聊天里没有一次"委托他人动我的东西"的场景，所以这条**无法用生活语料检验**，不能算支持也不能算反例 |
| **M5 减法优先** | **迁移最好的一条** | 给姐的处方是砍：「车先别考了」→「先搞钱了你现在的情况」[姐#L4903-L4904]；报班的结论是砍：「那我先不报 / 我自己学会」[爸#L409-L410]；连游戏也砍：「不打等会弄资料」[同学B#L12203] |
| **M6 可检查产出＝完成** | **对"交给别人的"成立，对"自己的"不成立** | 成立：承诺翻译→两天后交付并附口径说明（爸#L640 → #L650-L654）。不成立：学校例行打卡先后三次被辅导员点名未打 [辅导员#L62][#L72][#L73] |

**一句话**：M1/M2/M3/M4 是**对 AI 下指令时才被激活的语域**，不是他生活里的人格；M5/M6 是跨语域的真脾气，但 M6 只管"交给别人的东西"。所以不要用 M1 描述"他这个人很较真"——生活里 31 个月他只说过一次「我要看到证据」。准确说法是：**他在有验收方的时候才较真**。

## 4. 价值观补证

### 4.1 家庭责任（V5 从 2 处扩到 4 类，且是行动不是表态）

| 类型 | 证据 | 性质 |
|---|---|---|
| **给弟弟补课** | 2026-09 起持续给他弟上网课：排课、定时间、盯进度 [妈#L1816-L1840]；他判断进度「远超他们讲的课」[妈#L1845] | 无偿、持续、有交付 |
| **给父亲做翻译** | 爸发两份英文价格表 → 他两天后交中文版，并标注类别与单位 [爸#L634-L654] | 有交付物、有口径提醒 |
| **家庭议事有他的一票** | 父亲卖车库前专门问他：「你的意见呢」→ 他「我可以 / 我支持」→ 父「你也是家庭成员」[爸#L360-L365] | 被当成决策成员，不是被通知 |
| **担心弟弟** | 「我发现我弟性格变得很变扭了咋办」[姐#L6315]；「我弟还好不卖」[姐#L6371] | 主动求助式关心 |
| **钱** | 长期按月收家里生活费（父多次「已转」），也会主动要：「不够钱吃饭了」[妈#L2]、一句小额报销请求[妈#L1684] | 依赖是默认状态 |
| **对长辈的情绪照顾** | 「爱你老爸」[爸#L420]（单次，与整体极简风格不符，可能是要钱语境下的调侃） | 孤例，不外推 |

**不调和的并存**：同一周里他既在给弟弟无偿补课（9-05~9-19），又在接受小舅安排的实习证明（9-28）。**这两件事都是"对家里的责任"，方向相反。**

### 4.2 金钱观

- **大额先自付、不向家里要**：报班时第一句是「不用你们出钱 / 我自己寒假想办法赚」[爸#L368-L369]。同一模式在买课、买车票时重复：「反正不用你们出钱」[妈#L1246]。
- **小额直接开口**：吃饭钱、车票、几十块的花，全是直球索要。**分界线不是金额大小，是"这东西算不算投资自己"**。
- **对价格敏感但接受差价**：「楼下打不舒服」拒绝免费场地去打付费场 [妈#L1923]；母亲把多收的差价退回去并强调诚信，他回「[失望]」[妈#L1895-L1900]。价值判断句式是「得值这个价钱」[姐#L620]：「值」40 条、「贵」54 条。

### 4.3 学历与工作焦虑（本节是全新证据，SKILL 原来只有一句「双非」）

- **最直白的一句**：「双非计算机我看不到我的前途」[同学C#L714]，同段还有「我要去考985211」「考不上我就去送外卖了」「早知道当初去读警校了」[#L713-L719]。时间是 **2025-04**，比他开始秋招早一年半。
- **仰视式想象**：「很难想象那些985211是怎么样的」[妈#L1425]。
- **把自己的位置说成"我们这种"**：「就是说要等哪些92学生面完再到我们这种」[同学B#L11227]——不是愤怒，是陈述排队规则。
- **自我定位为"没技术的"**：姐说自己没技术，他接「我也没 / 我只会一点点」[姐#L6985-L6986]。

### 4.4 对朋友

- **给建议就给步骤，不给情绪**：姐工作受挫，他的回应是「车先别考了」「先搞钱了你现在的情况」，再补一句「一步一步走焦虑也没用了现在」[姐#L4903-L4906]。
- **立刻兑现请求**：姐让他问母亲有没有工作，他当场问、当场回「我妈说他留意一下」[姐#L4908-L4910]；朋友让他代打游戏活动，回「ok」[同学B#L12198]。
- **不占人便宜也不让人占**：请客梗高频（「请我」32 条、「我请你看电影你请我吃饭吧」[同学B#L1111]），但从不涉及借钱纠纷（「借钱」1 条，是对方开口）。
- **亲昵用"铁子语"不用"谢谢"**：「爱你么么哒」[同学E#L1077]、「宝宝别哭」[同学A#L4478]、「谁跟谁」[姐#L4914]。

### 4.5 恋爱/感情：证据不足

- 31 个月里没有任何一段恋爱关系的痕迹。「女朋友」相关 12 条全是**别人**的女朋友、或假设句（「还没有女朋友来安慰我」[同学A#L1054]、「那还没女朋友的来了」[同学A#L6525]）。
- 母亲唯一一次试探：「为什么？你失恋了？」——他答「没有刚起床」[妈#L1843-L1844]。
- **结论：证据不足。** 不写"单身"也不写"有对象"，只能写"聊天里没有出现过"。

### 5.5 最重的话给了抽卡，最轻的话给了失业

## 6. 幽默：与「幽默信号全关」冲突吗

**不冲突，但 03 的表述需要改口径。** 03 的结论是「哈哈 0、笑死 0、233 0、笑脸符号 0」——在生活语料里**依然几乎成立**：他「哈哈」11 条（0.04%），而对方 129 条（0.65%），**他笑的标记率是对手的 1/16**。

真正的事实是：**他不用"哈哈"标记幽默，他用另外四种形态。**

| 形态 | 数据 | 例 |
|---|---|---|
| **① 自称"爹"（最强指纹）** | 「你爹」70 次、「爹」75 次，而对方合计 5 次 | 「别骂你爹了」[同学F#L713]、「截个图给你爹看看」[#L1283]、「叫爹」[#L1515] |
| **② 群发段子（不是现场造梗）** | **29 条**同一天发给 ≥2 个不同联系人；最长一条 1,011 字发给 3 人 | 「牢九门规则怪谈」11:19 发 A、15:37 发 B [同学A#L2832][同学F#L718]；一条 462 字的游戏招募文 16:34 同时发 3 人 |
| **③ 666 / 牛逼 当笑声** | 「666」134、「牛逼」127、「牛」179，任一出现 313 条（1.13%）——**对方只有 0.20%，他夸人比被夸多** | 「羡慕你爹的十幻灵吗」[同学F#L1680] |
| **④ 表情代笑** | [捂脸]120、[呲牙]35、[偷笑]21、[破涕为笑]14 | 单条只有「[捂脸]」 |

**限定**：「自称爹」几乎只对**男性大学同学**使用（同学F、同学A）；对姐、对父母、对长辈 **0 次**。所以它是**同龄男性语域的专属梗**，不是通用幽默。

## 9. 本维度信息不足之处

1. **只有 16 个人，且全是熟人。** 没有同事、面试官、HR、陌生人、网友。**"他怎么跟不熟的人说话"零证据**，而这恰恰是面试语域。任何"他在面试里会……"的句子都不能从这里推。
2. **emoji 类型消息的内容全部丢失**（4,742 条被替换成「[表情]」）。他的表情包风格、玩梗图像、斗图行为**无法统计**，只能从方括号表情（1,192 处）间接看。
3. **没有语音、没有通话记录、没有朋友圈。** 语气、语速、面对面的反应全部缺失。对一个"句子只有 5 个字"的人，这层损失特别大。
4. **对方的回复只用来对照，没有做人格分析。** 所以"他的幽默好笑吗""他的安慰有用吗"**无法判断**。另一代价是：第三方一律改称关系后，失去了"同一个人在不同关系里的差异"——同学A（滚 45 条）与同学F（你爹 70 条）可能是两种相处模式，本文只能按"同学"处理。
5. **"实习证明"一节只写日志里有的动作。** 日志显示：父亲提议、小舅开具、阿勇叔盖章、他修改日期以满足学校周数要求 [爸#L617][小舅#L22-L29][阿勇叔#L27-L31]。**日志没有显示他对此的评价，本文也不给他加评价。** 需注意这是**学校实习证明**，与"简历上有没有实习"是两件事，不能互相证明。
6. **金额全部略去**（报班费、生活费、抽卡消费、票价）。因此"他的金钱观"只能写结构（大额自付/小额索要），不能写量级。
7. **2024-03 ~ 2025-03 只有零散会话**（姐、妈、爸、同学E），2025-09 ~ 2025-11 有断档。**"这几年他一直是这样的"仍然不成立**，只能说"在有记录的月份里反复出现"。
