# 雨落狂流之暗核心风格、影片基调、主要色调
核心风格：都市黑暗奇幻、青春宿命史诗和灾难公路片。粗颗粒胶片质感，低饱和浊色。一部从中国都市暴雨中驶入超自然世界的青春黑暗奇幻电影：现实质感承载亲情创伤，灾难奇观唤醒血统宿命，最终让一个孤独少年成为悲剧英雄。


影片基调：前半冷幽默，后半悲壮压迫，结尾留下孤独和宿命感；基调可按三层推进：1、都市青春的冷感荒诞；2、暴雨中的心理囚笼；3、超自然世界的悲剧降临。可参考理想基调观感：前半像王家卫式的都是孤独与黑色幽默，中段转入诺兰式的灾难悬疑，后端进入《龙族》式的青春悲剧史诗


主要色调：铅灰暴雨色为底，黄金瞳作命运信号，血红色用于失控时刻。本影片专属三色系统：铅灰、蓝黑、青绿色：现实世界的主色，代表台风、校园空场、车流和鹿芒（男主）的情感封闭。画面应低饱和、潮湿、反光强，像城市被雨水洗掉了温度；冷白、银蓝：学校灯光、车灯、仪表盘和高架路灯，表现现代文明的秩序感与冷漠感；暗金、琥珀金：只用于超自然血统、黄金瞳、炼金纹路或关键觉醒瞬间。金色不能铺满画面，越稀少越神圣、越危险；深红、刹车红、血红：用于父子争吵的爆点、龙族现象袭击、火焰、鲜血和失控状态，作为情绪和危险的视觉警报。具体的色彩弧线：校园冷蓝 → 车厢银黑 → 高架铅灰 → 超自然暗金 → 结尾灰烬般的冷金。


# 开场
画面风格：都市黑暗奇幻、青春宿命史诗、灾难公路片；粗颗粒胶片质感，低饱和铅灰、蓝黑和青绿色为主色，潮湿反光的城市表面，冷白和银蓝色人工灯光，现实主义灾难氛围中隐藏轻微超自然不安。


作为场景的视觉锚定：
-当代中国都市，玻璃幕墙的写字楼和高层住宅，地面则保留着较旧的沿街商铺、围墙、公交站和潮湿狭窄的生活街道。高级商场、商务酒店与封闭式住宅区之间，穿插着普通人的日常空间。建筑不必全部崭新，外墙可以有雨痕，混凝土高架有积垢，金属栏杆略显锈蚀


作为群像人物的视觉锚定：
-城市居民以普通通勤者、学生、外卖骑手、保安、环卫工人、商务人士、老人和带孩子的家庭为主。人物不作为单独主角出现，主要以中远景、背影、侧影、雨幕中的剪影和反光倒影呈现。
-服装以低饱和都市日常服为主：深色通勤外套、校服、雨衣、湿透的衬衫、黑色长裤、廉价透明雨伞和塑料袋。商务人士穿深灰或黑色西装，学生背着书包，骑手穿暗色防水服。避免鲜艳服装、统一制服和时尚广告感。
-人物状态是“城市正在失去秩序，但人们仍试图维持日常生活”：有人低头看手机确认台风消息，有人奔跑赶公交，有人扶住被风吹翻的雨伞，有人拖着行李匆忙进入住宅区，有人站在便利店门口等待雨势减弱。所有人都朝向建筑物、地铁口、公交站和停车场移动，形成明显的“回家潮”。

作为人物位置和状态的参考：
-前景：被雨水打湿的行人肩膀、透明雨伞、路面积水和车窗倒影快速掠过，人物只露出局部，制造压迫感和临场感。
-中景：公交站前拥挤的人群、奔跑的学生、拉着孩子的家长、拎着公文包的上班族，动作急促但克制。
-远景：高架桥上的车辆缓慢排成红色车流，写字楼窗户中零散亮起灯光，住宅楼下的人群不断涌入门厅。
-高层住宅内部：落地窗前的客厅保持安静，电视播放台风预警；窗外的城市人群和车流形成遥远、模糊、被雨水切碎的背景。
-整体状态：没有人直视镜头，没有夸张尖叫或灾难式奔逃，表现灾难尚未正式降临前的集体不安、疲惫和麻木。


分镜一：
镜头一，10秒单镜头连续运动，无剪辑、无跳切、无突然变焦。

当代中国沿海都市，台风登陆前一天，下午4点30分。都市黑暗奇幻、青春宿命史诗、灾难公路片。粗颗粒35mm胶片质感，低饱和铅灰、蓝黑、青绿色为主色，潮湿空气，强烈玻璃和路面积水反光。冷白和银蓝色人工灯光表现现代城市的秩序与冷漠，暗金色只作为极短暂的超自然预兆。

镜头全程锁定远处一栋高层住宅楼，目标楼栋位于画面中央偏右，外墙有明显的灰白雨痕，楼体旁边有一条竖直的青绿色灯带。镜头从这栋住宅楼上空开始，最终停在其中一扇客厅落地窗外。不要更换目标楼栋，不要切换到其他建筑。

【明确空间路径】
起点：目标住宅楼上方约80至120米，45度俯视。
路径：镜头向前、向下、沿直线靠近目标楼栋，始终保持目标住宅楼在画面中央偏右。
终点：目标楼栋中部偏上的一扇客厅落地窗外，距离玻璃约1.5米。
镜头最终停在窗外，不穿过玻璃，不进入客厅内部，不切换成室内机位。

【0—2秒：城市高空建立】
镜头从目标住宅楼上方开始，45度俯视城市街区。铅灰色台风云层压低天际线，小雨斜向落下。画面同时包含玻璃幕墙写字楼、高层住宅、老旧沿街商铺、公交站、人行道、机动车道和突出的混凝土高架桥。

高架桥上的车辆缓慢移动，车灯和刹车灯在雨幕中形成银灰色与暗红色光带。城市没有完全停摆，但所有人都在加快回家。女声新闻播报从远处传来，声音被风雨和建筑物遮挡，只能听见：

“台风沙德尔即将登陆，城市启动台风红色预警，请各位市民关紧门窗，尽量留在家中，不要外出……”

【人物位置固定】
前景只出现被雨水打湿的伞面、行人肩膀、车窗反光和路面积水，不出现完整人物脸部。
中景是地面上的公交站人群、学生、外卖骑手、商务人士和带孩子的家长，他们都向公交站、地铁口、停车场和住宅入口移动。
远景是高架桥上的车流、写字楼零散亮起的窗户和住宅楼下不断进入门厅的人群。
所有人物都在地面或建筑内部，不悬浮，不出现在高空，不直接看向镜头，不出现无目的的灾难式狂奔。

【2—5秒：向目标楼栋下降】
镜头沿直线向前下降，穿过雨幕，逐渐靠近目标住宅楼。目标楼栋始终保持在画面中央偏右，不能丢失。

镜头经过住宅楼外立面时，只短暂看到两三扇窗户中的生活片段：有人关窗，有人收起阳台衣物，有人抱着孩子进入房间。人物只作为窗后的模糊剪影出现，不进行人物特写。

地面上的人群继续向住宅区移动。透明雨伞被风吹得变形，学生护住书包，外卖骑手减速避让车辆，商务人士低头查看手机上的台风预警。人群动作急促但克制，表现灾难正式降临前的集体不安和麻木。

【5—8秒：靠近目标窗户】
镜头继续向目标楼栋下降并靠近，画面逐渐从城市全景变为住宅楼外立面。雨水附着在镜头前景，玻璃幕墙倒映着灰暗天空、车流和刹车红灯。

目标窗户必须清晰可见，窗内是一个普通家庭客厅，室内没有人物正面特写。客厅里只有电视发出冷白色光线，沙发、茶几、未收起的校服和书包暗示这里住着一个青春期少年家庭。

镜头仍然位于窗外，玻璃位于镜头和客厅之间。不要穿窗，不要进入室内。

【8—10秒：窗外停留】
镜头在落地窗外约1.5米处减速并停住，保持35mm视角。前景是缓慢滑落的雨滴，中景是湿润玻璃，背景是玻璃后的客厅和电视。

焦点从玻璃上的雨滴缓慢转移到客厅电视。电视正在播放台风预警，女主持人的声音从模糊逐渐变得清晰，风雨声退到背景：

“请市民尽快返回住所，避免前往临海区域。新一轮强降雨将在今晚八点后开始。”

电视画面短暂出现高架桥、积水街道和拥堵车流。画面边缘只闪过一瞬间极其微弱的暗金色反光，像信号故障，也像尚未被察觉的命运预兆。暗金色不能覆盖画面。

镜头停留在窗外，通过雨水和玻璃观看电视，随后自然切黑。

# 镜头二
故事脚本：
雨噼里啪啦打在窗上，操场上白茫茫一片。

下午还是晴天朗日，可随着下课铃响，眼看着铅色的云层从东南方推过来，天空在几分钟里黑了下去。跟着一声暴雷，成千上万吨水向着大地坠落，像是天空里的水库开了闸门。

足球场上车辙交错，草皮被翻得支离破碎。原本私家车不准进校园，但是这么险恶的天气，家长都担心自己孩子被淋着，几个人强行把铁门推开，所有的车一窝蜂地拥进来。半小时之前，操场上热闹得像是赶集，车停得横七竖八，应急灯闪着缭乱的黄光，每个人都死摁喇叭，大声喊自己孩子的名字。瓢泼大雨中，学生们找不到自家的车，没头苍蝇一样乱转。

现在所有人都被接走了，教学楼里和操场上都空荡荡的，“仕兰中学”的天蓝色校旗在暴风雨里急颤。

像是曲终人散。

教室里只剩下他一个人，灯光惨白，而外面黑得像是深夜。这种天就该早点回家。

他掏出手机拨号，把免提打开，放在桌上，默默地看着它。

电话“嘟、嘟”地响了几声后接通了，“子航你那里也下雨了吧？哎呀妈妈在久光商厦和姐妹们一起买东西呢，这边雨可大了，车都打不着，我们喝杯咖啡，等雨小点儿再走，你自己打个车赶快回家，或者打个电话叫你爸爸派车来接你。子航乖，妈妈啵一个。”话筒里果然传来清脆的“啵”声，而后电话挂断了。

楚子航收起手机，从头到尾他一个字都没说。他也没准备要说什么，他拨这个电话只是告诉妈妈自己没事，让她别担心，该玩接着玩。

所谓大人，有时候很愚蠢。孩子伸出手想去安慰她一下的时候，她还以为你在要吃的。

外面没车可打的，这么大的雨，出租司机也不想做生意，都早早开车回家了。久光商厦那边没有车，学校这边也一样，可妈妈想不到。姥姥说妈妈是个“毛头闺女”，没心肝的。楚子航也不想给“爸爸”打电话。“爸爸”是个很忙的人，不会记着下雨天派车来接继子这种琐事。但只要打电话提醒，“爸爸”一定会派司机来。“爸爸”是个优质、负责、有教养的好男人，很爱舞蹈演员出身的漂亮妈妈，爱屋及乌地也对他好，常挂在嘴边的话是，“子航啊，有什么需要就说出来，我是你爸爸，会对你尽义务的。”

有个有钱的“爸爸”要对他尽义务，听起来很不赖。

可楚子航觉得自己不需要。

教室门敞着，寒风夹着雨丝灌入，凉得刺骨。楚子航裹紧罩衫，把手抄在口袋里，接着发呆。
