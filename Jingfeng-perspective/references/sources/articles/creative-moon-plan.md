## 三、叙事处理

### 3.1 时间锚点

**锚点：婚后 · 孩子约 3-4 岁 · 某个秋日的川越。**

选这个点的理由：
- 它是官方明确给出（"育有一子"）但**从未展开**的区间 —— 属于**填补空白**，而非改动已有情节。
- 30 秒的容量只够承载一个极小的情感节拍，而"育儿中的一天"天然契合本作"日常即全部"的气质。
- 川越氷川神社的"家庭円満"神格，与这个阶段形成完整的意象闭环 —— 从初三的告白之夜开始，到一家三口在同一片月色下，完成一个循环。

### 3.2 最小补足（原意范围内的推断，已标注）

以下为导演补足，非原文事实：
- 孩子的性别、名字：**不予设定**。30 秒内不出现可辨认的文字/名字（也符合"H3 不依赖生成画面准确写入文字"的技术约束）。
- 小太郎是否出版过小说：**保持模糊**。他是公务员（既成事实），写作是未竟的梦 —— 这个张力就是本集的情感内核。
- 茜是否继续跑步：**保留**。她仍是那个会跑步的人，只是现在跑在晨间的河堤上。

### 3.3 本集剧情节点

> **节点**：小太郎深夜回家，发现茜在 LINE 上留了话。他走到窗边，夜色里孩子在睡、茜在等他；月亮很好。
>
> **原因**：小太郎加班晚归（公务员的日常），两人已有一阵没好好说话。
> **可见动作**：小太郎开门进屋 → 看见桌上的红薯吉祥物（旧的、褪色的那只）→ 掏手机看 LINE → 走到窗边望向月色。
> **结果**：他发现茜今晚也给他留了一句极短的话。
> **反应**：他对着手机打了个字，删掉，又打 —— 最后只发了一句。
> **转场**：屏幕黑，LINE 界面亮起，显示发送成功。

**情感落点**：成年版的小太郎，仍然不擅长把话说明白。而茜仍然听得懂。这与初三那晚的"月がきれい"是同一个动作的成年回声。

## 四、统一视觉方向

**视觉形式**：写实影像风漫剧（电影级实拍感）

| 项目 | 规格 |
|---|---|
| 画幅 | **16:9 横版** |
| 帧率 | **24fps** |
| 分辨率 | 本机基线 **640x352**（8GB VRAM 稳定档） |
| 质感 | 电影级写实，柔光，低饱和，自然主义布光 |
| 色调 | 暖黄室内光 vs 冷蓝夜色 —— 用色温讲"家里"与"外面"的分界 |
| 镜头语言 | 手持微晃 + 固定长镜交替；不用炫技运镜，保持本作的克制 |

**时代/地域设定（须一致）**
- 地点：埼玉县川越市，小太郎自小居住的独门独院（祖父母所建），延续他"一次都没搬过家"的设定。

- 室内陈设：老旧音响（父亲龙之介听黑胶的习惯留下的）、书架、孩子的玩具、褪色的红薯吉祥物。

## 五、30 秒单集逐镜分镜

**结构：2 镜。镜 1 = 16 秒，镜 2 = 14 秒。**

> 本机 H3 Lite 的原生输出是 **约 5 秒 / 124 帧 / 24fps**。30 秒需 **6 段 5 秒**生成后拼接（每镜 3 段 + 3 段）。这是本机产能的现实约束，已在 §6.4 说明。

### 镜 1 ｜「一握之砂」式归家（16 秒）

| 字段 | 内容 |
|---|---|
| 来源节点 | 导演补足（婚后日常） |
| 剧情任务 | 建立"成年小太郎的疲惫"与"家的存在"，为镜 2 的沉默做对照 |
| 时长 | 16 秒（生成 3 段 × 5 秒 + 1 秒余量） |
| **首帧静态状态** | 玄关内侧视角。木质鞋柜，柜面上一只**褪色发白的小红薯玩偶**。门缝透出暖黄光。 |
| 主动作弧 | 门从外推开 → 小太郎（30 代前半，深色大衣，领带松着）侧身进屋 → 脱鞋 → 目光落到鞋柜上的红薯玩偶 → 手指停了一下，把它摆正 |
| 可见结果 | 玩偶被摆正；他站在玄关没有立刻往里走 |
| 必要反应 | 屋内传来极轻的、孩子睡熟的呼吸声（不做成画面主体，仅声音） |
| 对白 | 无。本镜**完全无对白**，仅有环境音（保留原生环境声，非静音） |
| 景别 | 中景 → 手部特写 |
| 机位 | 玄关内侧低位固定 |
| 运镜 | 极缓的横向推移（右→左，幅度小），跟随他进屋的方向 |
| 空间方向 | 门在画面**左侧**（外），屋内纵深在**右侧**（内）。全镜不越轴 |
| 光线 | 室内暖黄（约 3000K），门外走廊冷白（约 5000K） |

## 六、生成方案

### 6.1 生成路线选择

| 镜 | 路线 | 依据 |
|---|---|---|
| 镜 1 | **I2VA**（首帧图生视频） | 需要精确控制红薯玩偶的位置与玄关构图。首帧由图像生成锁定，再驱动动作 |
| 镜 2 | **I2VA**（首帧图生视频） | 侧脸角度、手机屏光位、窗外月亮位置都需要先构图确认 |

**理由**：两镜都涉及"精确位置"（玩偶摆在柜面、窗与月亮的位置关系），属于需要入口画面解决的镜头类型，不适合用纯文生视频期待它自己摆对。

### 6.2 输入就绪清单

生成前需要三件资产的规范图：
1. **小太郎成年版**（30 代前半）—— 需与初三版五官基因为同一人，但加年龄感
2. **茜成年版**（镜 2 只需剪影，可后置）
3. **玄关场景 + 窗边场景**（同一住宅，光线延续）
